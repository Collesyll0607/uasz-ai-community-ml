# Projet Machine Learning — UASZ AI Community

**Auteure** : Collé Syll — Université Assane Seck de Ziguinchor (UASZ)  
**Technologies** : `Python`, `Pandas`, `NumPy`, `Scikit-learn`

## Présentation
Travaux pratiques et collaboratifs réalisés au sein de l'**UASZ AI Community** autour du cycle de vie d'un modèle de Machine Learning :
1. **Prétraitement & Normalisation** (`StandardScaler`, nettoyage et structuration des variables).
2. **Entraînement supervisé** (`RandomForestClassifier` & `GradientBoostingClassifier`).
3. **Évaluation rigoureuse** (`Accuracy`, `F1-Score`, matrice de classification).

## Exécution

```bash
python pipeline_uasz_ai.py
python -m unittest test_uasz_ml.py -v
```
